# 🏥 CareNest – Appointment Booking System

## 📌 Overview

**CareNest** is a full-stack healthcare appointment booking system that allows users to  view doctor details, 
book appointments, cancel appointments, manage their profile, and make online payments. The platform also provides an intuitive 
and responsive user interface for a smooth appointment-booking experience.

The project is built using modern web technologies and follows a client-server architecture.

## 🚀 Features

### 👤 User Features

* User registration and login
* Secure authentication using JWT
* Password hide/show functionality
* View and browse doctors
* View doctor details, availability, and fees
* Book appointments with doctors
* View booked appointments
* Cancel appointments
* Make online payments for appointments
* Manage and update user profile
* Edit address and personal information
* Responsive user interface

### 📅 Appointment Management

* Select an available appointment slot
* Book appointments
* View upcoming appointments
* Cancel appointments
* Reverse and display appointments in the required order
* Format appointment dates for better readability
* Calculate and display user age

### 💳 Payment

* Online payment integration for appointment booking
* Secure payment handling
* Appointment payment status management
